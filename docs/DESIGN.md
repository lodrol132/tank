# Territorial.io - Design Document

## Обзор проекта

Территориальная стратегия в реальном времени для Roblox с элементами захвата территорий, управления ресурсами и строительства.

## Основные компоненты

### 1. Система карты
- Сетка 16x12 регионов
- Каждый регион имеет тип (Ферма, Карьер, Завод и т.д.)
- Визуализация через SurfaceGui с Frame объектами

### 2. Система ресурсов
- 6 типов ресурсов
- Генерация в зависимости от типа региона
- Ограничение по максимуму

### 3. Боевая система
- Захват территорий через атаку
- Расчет боевой силы
- Потери войск

### 4. Система построек
- 9 типов зданий
- Производство и апгрейды
- Эффекты на боевую силу

## Поток данных

```
Client -> RemoteEvent -> Server -> Validation -> Apply -> Broadcast -> Update UI
```

## Баланс игры

### Стартовые ресурсы
- Войска: 100
- Золото: 500
- Бетон: 50
- Сталь: 25
- Топливо: 30
- Уран: 5

### Генерация ресурсов
- Фарма: 2 золота/сек
- Карьер: 3 бетона/сек
- Стальной завод: 2 стали/сек
- Нефтеперерабатывающий завод: 2.5 топлива/сек
- Завод обогащения: 0.5 урана/сек

## Условия победы

1. Контроль 50% территорий
2. Самое большое количество ресурсов
3. Выживание до конца раунда
