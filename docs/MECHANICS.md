# Игровые механики

## Захват территорий

### Процесс захвата
1. Игрок выбирает граничащую территорию противника
2. Отправляет войска для атаки
3. Рассчитывается боевая сила
4. Если атака успешна, территория переходит к нападающему
5. При поражении войска возвращаются в исходный регион

### Боевая сила
```
Attack Power = BaseAttack + (Troops / 100) * 0.5 + Buildings * Bonus
Defense Power = BaseDefense * 1.5 + DefenseBuildings * 0.05 + DefendingTroops * 0.3
```

## Управление ресурсами

### Производство
- Каждый регион генерирует ресурсы
- Разные типы регионов дают разные ресурсы
- Максимум ресурса ограничен

### Трата ресурсов
- Строительство зданий
- Найм войск
- Исследования (будущая система)

## Система построек

### Экономические
- Ферма: +2 золота/сек
- Карьер: +3 бетона/сек
- Заводы: производство улучшенных ресурсов

### Военные
- Посты обороны: +5% урона в радиусе
- Порты: улучшенная логистика
- Ядерные установки: одна на карту

### Инфраструктура
- Банк: +8 золота/тик
- Фабрики: 1.5x скорость производства

## Альянсы и дипломатия

### Формирование альянса
1. Один игрок предлагает альянс другому
2. Второй игрок принимает
3. Оба становятся союзниками

### Эффекты альянса
- Видимость позиций на карте
- Общая экономика (опционально)
- Общая оборона

## События на карте

Случайные события:
- Стихийные бедствия (урон зданиям)
- Находки (бонус ресурсов)
- Вторжения NPC
